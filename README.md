# 🏦 DC Banking System

A beginner-friendly banking system built with Python.

This project simulates basic banking operations through a terminal-based interface.

---

# ✨ Features

- 👤 Create Account
- 💰 Deposit Money
- 💸 Withdraw Money
- 📈 Check Balance
- 🧾 Transaction History
- 🚪 Exit System

---

# 🛠️ Technologies Used

- Python

---

# 📚 Programming Concepts Used

- Variables
- User Input
- if/elif/else Statements
- Arithmetic Operations
- Strings
- f-Strings
- Basic Backend Logic

---

# 🚀 How To Run

1. Install Python
2. Open terminal
3. Run:

```bash
python main.py
```
